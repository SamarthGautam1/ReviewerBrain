# experiments/archive/

Superseded historical scripts, kept for provenance only. They are NOT
maintained, may reference the old repository layout and deleted indexes,
and must not be run as part of the current pipeline.

- `step3_rag.py` — the v1 RAG experiment (hunk+comment document format).
  Its evaluation produced the 256-token truncation finding documented in
  `docs/experiments/step3_rag_v1_truncation.md`, which motivated the
  comment-first representation now in `src/reviewerbrain/`.
